Независимый учебный проект

BlackSource

Пространство для любопытных: OSINT, Python и цифровые инструменты. Разбираемся, как находить и упорядочивать информацию из открытых источников — спокойно, ответственно и с уважением к приватности.

О проекте

BlackSource начался с простой идеи, которая однажды пришла в голову: изучать открытые данные, учиться программировать на Python и делиться тем, что интересно. Здесь знания предназначены для обучения и законного использования.
